# International Debt Analysis

## Project Overview
This project analyzes international debt data using Python, SQL, MySQL, and Streamlit.

## Objective
The main objective is to analyze debt patterns across countries, indicators, and years and generate useful insights for data-driven decision making.

## Tools & Technologies
- Python
- Pandas
- MySQL
- SQL
- Streamlit
- Plotly

## Project Workflow
1. Data Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. MySQL Database Integration
5. SQL Analysis
6. Data Visualization
7. Streamlit Dashboard
8. Insights and Reporting

## Key Analysis
- Country-wise debt analysis
- Indicator-wise debt analysis
- Year-wise debt trends
- Top countries by external debt
- Debt records and indicator analysis
- Advanced SQL analysis

## Dashboard
The project includes an interactive Streamlit dashboard for exploring international debt data.

## SQL Queries
The project contains 30 analytical SQL queries covering basic, intermediate, and advanced analysis.

## Conclusion
The project provides a structured approach to understanding international debt patterns using data analysis, SQL, and interactive visualization.
